- Official project page: https://www.behance.net/gallery/220587045/Bubble-Sans-100-Free-Font
- Official download folder linked by the creator: https://drive.google.com/drive/folders/1InC_mE9gPnqnYU_Zg9L46tgzstHzSXiu
- Downloaded file: `Bubble Sans 1.01.zip`, Drive file ID `1WzrLAO8v9wNGWSXbpzELF04_ja2vZzHA`, 109,047 bytes.
- Archive SHA-256: `d2c03627f09cae76da7c405481eb997bf43e5b617e9cc8c6a4af1a2ac49710b5`.
- Archive contents: `CHANGELOG.txt`, `OFL.txt`, and `Bubble Sans 1.01.otf`.
- Original font file: `Bubble Sans 1.01.otf`, 198,372 bytes.
- Packaged file: `res/font/bubble_sans.otf`; only the resource filename changed and the bytes were not converted or modified.
- Font SHA-256: `fd3c1c0394565e8d9bd807c8a74ec7f7d308f16ae3cdbe36f8a35b2f14307292`.
- Fontconfig identity: `Bubble Sans|Regular|65601`; the font name table reports version `1.01`.
- Fontconfig charset begins `20-7e a0-ac ae-b4 b6-17f`; `fc-query` reports `pt` language support, covering the Portuguese Latin-1 letters.
- `fc-query --format '%{copyright}'` returned an empty field. The embedded name table copyright is `Copyright 2025 The Bubble Sans Project Authors (https://github.com/abayemes/bubblesans)`.
- License: SIL Open Font License 1.1, copied unchanged from the official archive.

The implementation plan originally anticipated a TTF. The official creator archive contains only the Regular OTF, so Yomotsu preserves that OTF rather than converting it or giving it a misleading `.ttf` extension.
