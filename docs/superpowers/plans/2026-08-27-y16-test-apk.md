# Yomotsu Y16 Integration and Test APK Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Integrate the three approved Y16 increments, update the test version, run preserved and new regressions, and produce a signed arm64 test APK artifact from the temporary branch without any official promotion.

**Architecture:** Version and workflow guards advance together from Y15/75 to Y16-test1/76. Local checks validate code and debug/release assembly; the existing branch-triggered GitHub Actions workflow supplies the canonical signing secrets, preserves updater/OCR/signature guards, and uploads an artifact only.

**Tech Stack:** Gradle, JUnit Jupiter, Spotless, Android build tools, GitHub Actions, AAPT, apksigner, SHA-256 asset checks.

**Spec:** `docs/superpowers/specs/2026-08-27-y16-reader-polish-design.md`

- Execute after the fonts/migration, auto-scroll, and cover-accent plans on `agent/y16-reader-polish-test1`.

- Stop after presenting the test artifact and wait for the user's phone-test approval.
