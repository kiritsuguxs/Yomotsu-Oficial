# Y17 Comic Fit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Improve Yomotsu's existing balloon grouping and translated-text AutoFit while preserving OCR, translators, storage, and rendering compatibility.

**Architecture:** Extend `TranslationBlockGrouper` with additional visual-similarity evidence and hard mismatch guards, then harden the existing Compose AutoFit path rather than replacing it. Keep `SpeechBubbleAnalyzer`, OCR engines, translation providers, and persisted block schema unchanged.

**Tech Stack:** Kotlin, Jetpack Compose `SubcomposeLayout`/`Text`, JUnit, Gradle Android build.

**Spec:** `docs/superpowers/specs/2026-08-29-y17-comic-fit-design.md`

## Global Constraints
- Work only on `agent/y17-comic-fit-test1` based on `yomotsu-independent`.
- No PR, merge, release, applicationId/signature/updater change.
- Do not alter ML Kit, PaddleOCR models/recognition, translators, memory, cache, glossary, manual editing, fonts, or auto-scroll.
- Preserve old translation JSON compatibility and `Hyphens.None`.
- No new heavy image/model pass.
