# Yomotsu Y13-test1 OCR2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a manually selectable, English-optimized PaddleOCR engine beside ML Kit while preserving the complete Y12 translation pipeline and producing a signed Y13-test1 APK.

**Architecture:** A provider-neutral OCR contract returns Yomotsu-owned text geometry. ML Kit and PaddleOCR adapt their native results into that contract; `ChapterTranslator` continues from neutral blocks into the unchanged grouping, translation, glossary, memory, cleanup, and serialization path. PaddlePaddle's official Android SDK is vendored as a pinned source module with official PP-OCRv5 Mobile detector and English recognizer assets.

**Tech Stack:** Kotlin, Android 8+ (`minSdk 26`), Jetpack Compose preferences, Google ML Kit, PaddleOCR Android SDK, ONNX Runtime Android 1.21.1, OpenCV Android 4.5.3, JUnit Jupiter, Gradle 9.3.1, GitHub Actions.

- [ ] **Step 3: Implement the stable provider values and neutral contract**

```kotlin
enum class OcrEngineType(val preferenceValue: Int) {
    ML_KIT(0),
    PADDLE_OCR(1);

    fun supports(language: TextRecognizerLanguage): Boolean =
        this == ML_KIT || language == TextRecognizerLanguage.ENGLISH

    companion object {
        fun fromPreferenceValue(value: Int) = entries.firstOrNull { it.preferenceValue == value } ?: ML_KIT
        fun fromPref(pref: Preference<Int>): OcrEngineType {
            val type = fromPreferenceValue(pref.get())
            if (type.preferenceValue != pref.get()) pref.set(ML_KIT.preferenceValue)
            return type
        }
    }
}
```

```kotlin
data class OcrPoint(val x: Float, val y: Float)
data class OcrTextBlock(
    val text: String,
    val x: Float,
    val y: Float,
    val width: Float,
    val height: Float,
    val symbolWidth: Float,
    val symbolHeight: Float,
    val angle: Float,
    val confidence: Float? = null,
)
data class OcrPage(val width: Int, val height: Int, val blocks: List<OcrTextBlock>)
class OcrImage(val uri: Uri, val openInputStream: () -> InputStream)

interface OcrEngine {
    val type: OcrEngineType
    val language: TextRecognizerLanguage
    suspend fun recognize(image: OcrImage): OcrPage
    suspend fun release()
}
```

object OcrEngineFactory {
    fun create(
        context: Context,
        type: OcrEngineType,
        language: TextRecognizerLanguage,
    ): OcrEngine {
        require(type.supports(language)) { "PaddleOCR requires English source text" }
        return when (type) {
            OcrEngineType.ML_KIT -> MlKitOcrEngine(context, language)
            OcrEngineType.PADDLE_OCR -> PaddleOcrEngine(context, language)
        }
    }
}
