Adapted detector-only files: Detector.kt (DbnetPostprocessor), ImageOps.kt
(DbnetPixels / DbnetService resize), Geometry.kt (DbnetGeometry),
NcnnBackend.kt and ncnn_jni.cpp (DbnetSession / DbnetNativeBackend / dbnet_jni.cpp),
and NCNN build configuration. Original author/project credits are retained here
and in source headers. Upstream detector code is GPL-3.0; full text is included
in GPL-3.0.txt. This experiment includes modifications made for Yomotsu in 2026:
bounded immutable geometry, shape/handle validation, neutral coordinates,
stream-verified external models and a separate Android process. It does not
include upstream OCR, translation, renderer, inpainting or storage pipeline.
